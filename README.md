# autoshorts ✂️📱

Длинный стрим, подкаст или фильм → вертикальные **шорты 9:16** для TikTok, Reels и YouTube Shorts или **сборка смешных моментов** одним видео.
Сам находит моменты, ставит вебку стримера сверху и игру снизу (или кадрирует по говорящему), рисует субтитры по одному слову.

```bash
python autoshorts.py stream.mp4 -n 10                  # шорты, моменты выбирают агенты
python autoshorts.py "https://vkvideo.ru/video-…" --to 1h -n 5   # по ссылке: скачает только первый час
python autoshorts.py stream.mp4 -n 10 --ai             # моменты, темы, подписи и хэштеги — Claude
python autoshorts.py stream.mp4 --bg satisfying        # вебка сверху, «залипалка» снизу
python autoshorts.py stream.mp4 --compile -n 12        # «смешные моменты» одним видео
python autoshorts.py stream.mp4 --funny -n 8           # шорты из самых смешных моментов
python autoshorts.py movie.mp4 --style cinema --look cinema --fx particles --punch   # кино-эдит
```

## Режим «кинул и забыл»
Запустите `watch.bat` (Windows) или `./watch.sh` (Mac/Linux) и кидайте стримы и фильмы в папку `inbox/`.
Каждый файл нарежется сам, когда докачается, в `results/<имя файла>/`. Вместо видео можно положить `.txt` со ссылкой и флагами: `https://vkvideo.ru/video-… --to 1h -n 5`. Флаги передаются дальше: `watch.bat -n 8 --ai`.
То же вручную: `python autoshorts.py --watch inbox -o results -n 8`.

## Что умеет
| | |
|---|---|
| **Ссылки** | VK Видео, YouTube, Twitch, Rutube и всё, что умеет yt-dlp. С `--from`/`--to` из длинного эфира скачивается только нужный кусок, а не все три часа |
| **Агенты для шортов** | кандидаты — интересные (истории, споры, крючки) и смешные/ироничные вместе, в 3 раза больше нужного → точная расшифровка → локальная Qwen3-4B в роли судей **крючок** (цепляет ли первые 3 с), **история** (есть ли развязка), **зритель TikTok** → **редактор** выбирает итог и пишет заголовок-крючок по словам момента |
| **Поиск моментов** | эвристика: крючки в начале фразы, эмоции, всплески громкости, темп речи; моменты по границам фраз; статичная картинка (меню, лобби, AFK) топит оценку |
| **С Claude** (`--ai`) | Claude читает расшифровку целиком, выбирает самостоятельные моменты с панчлайном, пишет заголовок, крючок, подпись и хэштеги → `posts.txt`. Без `--ai` в `posts.txt` только время и заголовок из фразы |
| **Раскладка** | вебка стримера (лицо + края оверлея) сверху, игра снизу; студия, общение, несколько человек → **на весь экран 9:16**, кадр каждые ~3 с переходит на того, кто говорит (по движению губ); без людей в кадре → видео целиком на размытом фоне |
| **Фильмы** | находит монтажные склейки и на каждой переводит кадр на говорящего: нейросетевой детектор лиц YuNet (видит повороты и профили) + движение губ |
| **Субтитры** | по одному слову на стыке половин: `stream` (жёлтый), `soft`, `italic`, `bold`/`tilt`/`clean`, `glow`, `cinema`; строчные, без знаков; в паузах — `*СМЕЁТСЯ*`, `*КРИЧИТ*` |
| **Синхронизация** | текст распознаёт whisper `large-v3-turbo` с запасом ±2 с вокруг момента, время каждого слова уточняется wav2vec2 (forced alignment, как в WhisperX); куски речи, пропущенные whisper на шуме, дораспознаются по детектору речи; известные «галлюцинации» на музыке убираются |
| **Смешное** (`--compile`, `--funny`) | 1) кандидаты в 3 раза больше нужного: реакции в речи, ритм «ха-ха» в звуке, пики смеха; 2) каждый кандидат точно распознаётся заново; 3) нейросеть AudioSet (AST) слышит смех, хихиканье, крики и пение; 4) «агенты» — локальная Qwen3-4B в роли трёх судей (**ироник**, **панчлайн**, **зритель TikTok**) голосуют, **редактор** выбирает итог и пишет ироничные подписи. Всё офлайн, без ключей. `--quick` — только эвристика |
| **Сборка** (`--compile`) | моменты 5–25 с склеиваются с белой вспышкой и свушем; `--format horizontal` — 16:9 |
| **Звук** | −14 LUFS (двухпроходная нормализация), плавный конец |
| **Самопроверка** | каждый готовый ролик проверяется: длина, 1080×1920, звук, громкость, чёрный экран, «замёрзшая» картинка; замечания — в консоли и `report.json` |
| **Обложки и посты** | `short_01_cover.jpg` — кадр с лицом покрупнее в паузе между субтитрами + заголовок крупно; в `posts.txt` к каждому ролику заголовок, описание и хэштеги (пишет локальная модель) |

## Установка
Python 3.10+ и **ffmpeg с libass и libx264**:
- Windows: `winget install ffmpeg` (или сборка gyan.dev «full»);
- Mac: `brew install ffmpeg-full` и `export PATH="$(brew --prefix ffmpeg-full)/bin:$PATH"` — обычный `ffmpeg` из Homebrew собран без libass;
- Linux: `apt install ffmpeg`.

```bash
pip install -r requirements.txt
pip install -r requirements-align.txt   # по желанию: точная синхронизация субтитров и детектор смеха (torch + transformers)
pip install -r requirements-funny.txt   # по желанию: судьи смешного — локальная языковая модель (llama-cpp-python)
```
Программа сама проверяет ffmpeg при старте и скажет, чего не хватает.

**Первый запуск скачивает модели (один раз, нужен интернет):** whisper base ~145 МБ, whisper large-v3-turbo ~1.6 ГБ, wav2vec2 ~1.3 ГБ на язык (ru/en; для других языков — запасной способ синхронизации); для смешного — AST ~350 МБ и Qwen3-4B ~2.5 ГБ (свой файл GGUF: переменная `AUTOSHORTS_LLM`). Дальше всё работает офлайн, кроме `--ai`.

Для `--ai`: ключ Claude API в переменной `ANTHROPIC_API_KEY` (Windows PowerShell: `$env:ANTHROPIC_API_KEY="..."`, bash: `export ANTHROPIC_API_KEY=...`) или `ant auth login`.

## Параметры
| Флаг | По умолчанию | |
|---|---|---|
| `--from` / `--to` | | кусок видео: `90`, `15m`, `1h`, `1:20:00` |
| `--at` | | свои моменты вместо автоподбора: `37:56-38:54,2679-2736` (время в исходнике, края подтянутся к словам) |
| `-o` | out | папка результатов |
| `-n` | 5 | сколько шортов / моментов в сборке |
| `--min` / `--max` | 15 / 60 (со `--compile` 5 / 25) | длина момента, с; агенты подбирают длину по содержанию: шутка — 15–25 с, история — 30–60 с |
| `--lang` | ru | язык речи |
| `--model` | base | whisper для поиска по всему видео (`tiny` быстрее, `small` точнее) |
| `--caption-model` | large-v3-turbo | whisper для субтитров выбранных кусков |
| `--no-align` | | без wav2vec2-синхронизации (быстрее, менее точно) |
| `--device` | cpu | `cuda` — видеокарта NVIDIA (нужны CUDA 12 и cuDNN 9) |
| `--ai`, `--topic` | | моменты и тексты от Claude; тематика канала как подсказка |
| `--layout` | auto | `split`, `face`, `fit` |
| `--cam` | авто | рамка вебки `x,y,w,h` в пикселях исходника |
| `--bg` | игра из стрима | путь к видео или `satisfying` |
| `--style` | stream | `stream`, `soft`, `italic`, `bold`, `tilt`, `clean`, `glow`, `cinema` |
| `--look` | none | цветокор `cinema`, `cold`, `warm` |
| `--fx` | none | `particles` — частицы поверх кадра |
| `--punch` | | удары зумом на громких словах |
| `--compile`, `--format` | | сборка одним видео; `vertical` 9:16 или `horizontal` 16:9 |
| `--funny` | | шорты из самых смешных моментов |
| `--quick` | | без агентов: только эвристика (быстрее, хуже) |
| `--title`, `--bar` | | заголовок-крючок первые 3 с / полоска прогресса |

На выходе в папке `-o`: `short_01.mp4 …` и обложки `short_01_cover.jpg …` (или `compilation.mp4` + обложка), `posts.txt` — готовые подписи для публикации, `report.json` — тайминги, оценки судей и почему выбран момент, итоги проверки.
Расшифровка кэшируется в той же папке отдельно для каждого видео, языка и модели — повторный запуск не распознаёт заново.

## Скорость (замер, 4 ядра CPU без видеокарты)
Стрим 2 ч 49 мин: распознавание `base` — 47 мин, движение в кадре — 3 мин; каждый шорт — 2–3 мин (точное распознавание куска + синхронизация + рендер). С `--device cuda` распознавание в разы быстрее.

## Проверка агентом Claude Code
В `.claude/agents/irony-judge.md` — агент-редактор: открывает `report.json`, оценивает каждый момент 0–10 по критериям иронии и реакции, предлагает что выкинуть, порядок и подписи. В Claude Code: «проверь results/stream агентом irony-judge».

## Ограничения
- Без `--ai` и без судей (`--quick` или нет llama-cpp-python) моменты выбираются по словам, эмоциям, громкости и движению, а не по смыслу — бывают «пустые» куски.
- Судьи — небольшая модель 4B: тонкую иронию понимает не всегда, расшифровка шумного стрима тоже с ошибками. Отбор смешного добавляет ~10–15 мин на 4 ядрах.
- Говорящего в фильме определяем по движению губ — в сценах, где говорят за кадром, кадр остаётся на видимом лице.
- Субтитры по одному слову; ошибки распознавания на очень шумном звуке возможны.
